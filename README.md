# Unreasonable-target

ローカルLLM（Ollama）で動く「第二の自分」のアプリを2つ収めたリポジトリです。どちらも外部APIにデータを送らず、このPCの中だけで動きます。

| アプリ | 起動 | 内容 |
|---|---|---|
| [第二の自分（AIエージェント）](#第二の自分--あなたの代わりに考えて動くaiエージェント) | `起動.bat` | 声や文字で頼むと、手順を考えて作業・お任せ・お知らせ・ダブルブッキング調整をこなすデスクトップアプリ |
| [赤ペン先生デスク](#otamesi--赤ペン先生デスク第二の自分) | `start.bat` | 教務の先生の分身。学期予定・時間割・空き日さがし・提出物の仕分けを手伝うWebアプリ |

---

## 第二の自分 — あなたの代わりに考えて動くAIエージェント

声で「これをしといて」と頼むと、AIエージェントが自分で手順を考え、道具を順に使って片付けます。本人が休んでいる間も作業を進め、気づいたことは自分から知らせます。
外部APIには一切データを送信せず、すべてローカルで完結します。構想は [docs/system_architecture_concept.md](docs/system_architecture_concept.md) を参照。

```
[音声] → 1. Whisper（文字起こし）
       → 2. Ollama（エージェント: やることリストを作り、1手順ずつ道具を選んで実行）
       → 3. Python（コード抽出・BOM付きUTF-8で保存）
       → 4. PowerShell（実行・予約・通知・読み上げ・下書きを開く）
```

### エージェントの特徴

- **自分で考えて複数の作業をこなす** — 「予定を確認して、重なってたら調整案を作って、明日の朝8時に知らせて」のような頼みを、やることリストに分けて1つずつ実行します（考えた手順は画面に表示）
- **会話を覚えている** — 「さっきのお知らせ、やっぱり9時にして」のように前のやりとりを踏まえて話せます。次に起動しても続きから話せます
- **自分から気づいて知らせる** — 15分ごとに予定とお任せ作業を見回り、ダブルブッキングや作業の完了・エラーに気づいたら Windows の通知と声で知らせます
- **声で返事をする** — Windows 標準の音声合成で返事を読み上げます（「🔊 声で返事」で切り替え）

### エージェントが使える道具

| 道具 | すること |
|---|---|
| 予定の確認 | カレンダー（.ics）から予定・ダブルブッキング・空き時間を調べる |
| ダブルブッキングの調整 | 優先順位で残す予定を決め、相手への日程変更の連絡文を作る |
| 今すぐ実行 | PowerShell スクリプトや Web サイトを作って実行し、結果を受け取る |
| お任せ | 作業を今すぐ裏で / 指定時刻に1回 / 毎日・毎週 実行する（タスクスケジューラ） |
| お知らせ | 指定時刻に Windows の通知と声で知らせる |
| お任せの確認・日時変更・取り消し | お任せした作業が実行されたか、結果やエラーを調べる |
| メッセージの下書き | 自分の文体で返信・連絡文の下書きを作る（送信はしない。宛先は本人に聞く） |

作業の実行やお任せの前には、確認画面で「この作業ですること」を確かめてから進めます。

### セットアップ

1. [Ollama](https://ollama.com/) をインストールし、モデルを取得
   ```
   ollama pull qwen2.5:14b
   ollama pull qwen2.5:7b
   ollama pull qwen2.5-coder:7b
   ollama pull nomic-embed-text
   ```
   - `qwen2.5:14b` — エージェントの頭脳（手順を考えて道具を使う）。GPUのメモリが12GB程度あれば動きます。無い場合は `qwen2.5:7b` で代用しますが、複数の作業を頼んだときに手順を飛ばすことがあります
   - `qwen2.5:7b` — 返信・調整案などの文章
   - `qwen2.5-coder:7b` — PowerShell スクリプトの生成
2. Python の依存パッケージをインストール
   ```
   pip install -r requirements.txt
   ```

### 使い方

**デスクトップの「第二の自分」か、`起動.bat` をダブルクリック**すると画面が開きます（AI の Ollama が止まっていれば自動で起動します）。

1. 初回は「自分の情報」（名前・署名・予定の優先順位）を登録する
2. 下の入力欄に頼みたいことを書いて「送信」（マイクがあれば「🎤 話す」で声でも頼めます）
3. エージェントが「📝 やること」を考え、「🔧」の道具を順に使って作業し、最後に結果を報告します
4. 実行・お任せの前の確認画面では「はい、お願いします」か「やめる」を選ぶ。宛先などを聞かれたら文字か「🎤 声で入力」で答える

左のメニュー:
- **＋ 新しい会話** — これまでの会話を忘れて新しく始める
- **👤 自分の情報** — 名前・署名・予定の優先順位を変更
- **📅 予定を読み込む** — Google カレンダーや Outlook から書き出した .ics を選んで読み込む
- **📋 お任せ一覧** — お任せした作業の状況の確認と取り消し
- **声で返事** — 返事やお知らせを読み上げるか
- **テーマ** — 自動（Windowsの設定に合わせる）/ ライト / ダーク

パーソナルデータは `data/` に保存されます（GitHubには上げない設定です）。

ターミナルで使う場合:
```
python main.py          # 音声で話しかける
python main.py --text   # マイクが無いときはキーボードで入力
```

### ファイル構成

- `gui.py` — 画面（入力・確認・設定・見回り）
- `agent.py` — エージェント（やることリスト・道具の選択・会話の記憶・見回り）
- `main.py` — 道具の中身（文字起こし・コード生成・保存・PowerShell 実行・通知・読み上げ）

設定:
- `agent.py` の `AGENT_MODEL` — エージェントの頭脳のモデル
- `main.py` の `MODEL_NAME` / `TEXT_MODEL` — コード用 / 文章用のモデル
- `main.py` の `WHISPER_MODEL` — 文字起こしの精度と速度（`small` が標準）
- `main.py` の `CONFIRM_BEFORE_RUN` — 実行・お任せの前に確認するか
- `main.py` の `WORK_HOURS` — 予定の調整案で、空き時間として扱う時間帯
- `gui.py` の `MONITOR_MINUTES` — 自分から見回る間隔

## otamesi — 赤ペン先生デスク（第二の自分）

学校の教務の先生の「デジタル分身」を目指した試作アプリです。
学期予定・時間割・空き日さがし・提出物の仕分けを、**このPCの中だけで**手伝います。

### 起動
1. [Ollama](https://ollama.com/download) を入れて、モデルを取得する
   ```
   ollama pull qwen2.5:7b
   ```
2. `start.bat` をダブルクリック（または `py server.py`）
3. ブラウザで `http://127.0.0.1:8765/` が開きます。終了は黒い画面で Ctrl+C

音声入力を使う場合だけ、Whisper を入れます（ほかの機能は標準ライブラリだけで動きます）。
```
py -m pip install faster-whisper
```
初めて声で入力したときに、Whisper のモデル（small・数百MB）が自動でダウンロードされます。
モデルは環境変数で変えられます（例：`set WHISPER_MODEL=medium`、GPU を使うなら `set WHISPER_DEVICE=cuda` ※CUDA のライブラリが別途必要）。

`web/index.html` を直接開いても動きますが、その場合は分身（AI）と音声入力が使えず、AIなしの機能だけになります。

### 機能
| 機能 | プログラムがすること | 分身（Ollama）がすること |
|---|---|---|
| 一括仕分け＆3行要約 | 提出ファイルの読み込み、言葉による簡易判定 | 3行要約、学生の様子の判断（良好・注意・要面談）と理由、先生の文体での声かけの下書き |
| 学期予定 | 祝日・休みを除いた曜日ごとの授業回数、振替授業日の候補 | 話し言葉の予定（「2月の第2週は後期試験」）を休み・行事・振替に変換、学生向けのお知らせ文 |
| 時間割 | 外部講師の来校条件を満たす時間割の自動作成、入れ替えと固定 | 講師からの連絡（メール・電話メモ）を来校できるコマに変換、講師への連絡文 |
| 空き日さがし | 時間割・学期予定・自分の予定から空いている日とコマを検索 | 依頼（「来週、山田さんと面談を2コマ」）を検索条件に変換、先生の文体で日程候補の文面 |
| 音声入力 | 「声で入力」で録音し、Whisper（このPC内）で文字にする | 文字にした内容を続けて読み取る。面談メモは仕分けの一覧に入り、要約と様子の判断ができる |

### 設計の考え方（要件との対応）
- **ローカルLLM（セキュリティ）**：AIの処理はこのPCの Ollama だけで行います。`server.py` は `127.0.0.1` にだけ待ち受け、Ollama のうち一覧（`/api/tags`）と会話（`/api/chat`）だけを取り次ぎます。
- **量子化（学校のPC環境）**：量子化済みのモデルを使います。GPUのない事務用PCでは `llama3.2:3b` などの軽いモデルを、画面の「分身の設定」で選べます。
- **パーソナルデータ（先生らしさ）**：「分身の設定」に貼った普段のメールの文体を真似て文面を書きます。
- **計算はプログラム、言葉は分身**：日付の計算・時間割の組み合わせ・空き日の検索はプログラムが行います。分身は言葉を条件に直すだけで、読み取った内容は画面で確認してから反映します。
  - 「◯月第n週」は分身に週の名前を選ばせ、日付はプログラムが求めます。「12/21」のような月日も、年はプログラムが学期から決めます。
  - 文面の中の一覧（担当コマ・日程候補・予定）は、プログラムが正確に作って差し込みます。
  - 文面に計算結果にない日付が入っていれば、警告を出します。
- **音声認識（入力の手間）**：録音は `server.py` の Whisper がメモリ上で文字にし、ファイルには残しません。CPU で動く small モデルを int8 に量子化して使います。学校でよく使う言葉と名簿をヒントとして渡し、「進路面談」などの聞きまちがいを減らしています。
- **最後に決めるのは先生**：分身が作るのは下書きです。入力した内容はどこにも保存しません。

### まだないもの
- RAG（学生便覧などの学校ルールの読み込み）と書類の不備チェック：書類チェック機能をいったん外したため、未実装です。
- `legacy/` は最初に作った Streamlit 版です（参考用）。
